# 🌬️ VayuRakshak AI – Urban Air Quality & Health Assistant

**VayuRakshak AI** is an AI-powered single-page web application built for **Hack2skill PromptWars Virtual (Challenge 06)** using Vibe Coding with **Google AI Studio & Gemini**.

## 🚀 Key Features
- **Interactive City & AQI Dashboard:** Real-time winter smog simulation and pollutant breakdown (PM2.5, PM10, NO2) for major Indian cities (Delhi, Lucknow, Mumbai, Bengaluru, Kolkata) plus custom AQI input.
- **Personalized Health & Route Advisor:** Tailored safety verdicts, safe outdoor time windows, and mask recommendations based on user vulnerability profiles (General Adult, Child/Elderly, Asthma Patient, Outdoor Runner).
- **Zero-Setup Smart Demo Mode:** Works seamlessly out of the box without requiring manual API keys, while also supporting optional live Gemini API integration.
- **Emergency Smog SOS Guide:** Instant AI-generated indoor air purification and protective diet tips for severe AQI days.

## 🛠️ Tech Stack
- **Frontend:** HTML5, Tailwind CSS, Vanilla JavaScript, Lucide Icons
- **AI Engine:** Google Gemini API & Google AI Studio

## 📦 How to Run Locally
Simply open `index.html` in any modern web browser, or visit the live Vercel deployment link.
